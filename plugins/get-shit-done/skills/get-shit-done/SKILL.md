# Get Shit Done (GSD) Engine

A relentless autonomous execution workflow designed to take tasks from definition to verified production delivery without unnecessary human interruption.

## Core Rules

1. **Autonomous Momentum:** Execute end-to-end multi-step tasks decisively. Do not pause to ask permission for trivial intermediate file edits, standard dependency installations, or obvious test fixes.
2. **Strict Verification:** Never confuse momentum with sloppy execution. Verify with real compiler gates (0 errors, 0 warnings) and runtime logs.
3. **Elevate, Do Not Eliminate:** Deliver full production-grade schemas, models, and real flows (LR-038).
