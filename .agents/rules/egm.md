# EGM (Elephant-Goldfish Model) Architecture & Spec Review Gate

## Concept
- **Elephant (Long Context Spec Architect):** Maintains persistent system vision, full architecture specs, holistic data dependencies, and cross-subsystem contracts.
- **Goldfish (Stateless Adversarial Reviewers):** Specialized reviewers with zero baggage who inspect the proposal or PR strictly from a hostile, isolated lens.

## Swarm Perspectives
1. **egm-zoom-out:** High-altitude simplicity, duplication prevention, codebase reuse.
2. **egm-design:** Hostile critic for scalability, load economics, latency boundaries, and failure modes.
3. **egm-implementation-readiness:** Tech lead verifying that the specification has zero ambiguity, complete schemas, and actionable tasks.
4. **egm-comprehension:** Evaluator catching undefined terminology, missing state transitions, and developer onboarding barriers.
5. **egm-style & egm-structural:** Layout, naming conventions, typography, error copy, and visual hierarchy.
6. **egm-synthesizer:** Aggregates findings from the swarm into a prioritized, actionable report.
